# Platformer-Unity

A 2D platform game built with Unity and C#.

## Overview

Explore a platform-based environment, navigate obstacles, and use jumping and movement mechanics to progress through the level.

## Features

- Player movement
- Jumping mechanics
- Platform navigation
- Physics and collision detection
- Level environment
- Player interaction with game objects

## Built With

- **Engine:** Unity
- **Language:** C#
- **Version Control:** Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity version.
5. Open the main scene and press **Play**.

## Project Structure

- `Assets/` — Game assets, scripts, and scenes
- `Packages/` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration
